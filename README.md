# evo-feature-opt

Optimización evolutiva de atributos para regresión (práctica de IA bioinspirada, UC3M).
El diseño completo y la fuente de verdad es [`docs/DISENO.md`](docs/DISENO.md).

## Instalación

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
pytest
```

Los datos originales están en `data/raw/` y no se modifican.
Cómo reproducir cada resultado se irá añadiendo conforme se completen los hitos.
